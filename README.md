# Tiếng Anh 30 ngày

App Android giúp người mới bắt đầu giao tiếp tiếng Anh trong 30 ngày: sửa phát âm và cách đọc chữ trước, rồi luyện giao tiếp công việc và lớp training máy hóa sinh AU480/DxC 700 AU.

Kế hoạch tổng quan: https://claude.ai/code/artifact/c700f6cb-ae2e-4f88-b3c1-faefa87746c5

## Cài app

- **Android:** vào tab Actions, mở lần build "Build APK" mới nhất, tải `tieng-anh-30-ngay-apk` trong mục Artifacts, giải nén và cài `app-debug.apk`.
- **iPhone:** mở https://yeuthamclub.github.io/App-Tieng-anh/ bằng Safari, bấm Chia sẻ > Thêm vào Màn hình chính. (Lần đầu cần bật GitHub Pages: Settings > Pages > Source: GitHub Actions.)

Nội dung bài học nằm ở `app/src/main/assets/lessons.json`, dùng chung cho cả hai bản.
